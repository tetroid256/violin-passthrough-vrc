# 左手のトラッキングが外れるとき

指板を押さえている左手は、ハンドトラッキングが外れやすい姿勢です（手のひらが顔の方を向き、指がネックと弦に隠れ、頭のすぐ近くにある）。
ここでは、外れたときに何が困るかと、その対策をまとめます。

## 何が困るか

| 困ること | 本アプリで対策できるか |
|---|---|
| 自動モード（構えたときだけ窓を出す）が、構えているかを判定できない | できる（下の 1〜3） |
| キャリブレーションが「CAL FAIL: NO LEFT HAND」で失敗する | できる（最後の 1 秒の平均。自動で効く） |
| 左手に追従させた窓（`anchor.type: device`）が止まる・消える | できる（窓を HMD 基準にする、または楽器のトラッカーに追従させる） |
| VRChat のアバターの左手が飛ぶ・固まる | **本アプリではできない**（VRChat は手の位置をコントローラー／VD のハンドトラッキングから取る。下の 4 を参照） |

既定の窓は HMD 基準なので、ハンドトラッキングが外れても窓は消えません。パススルーには本物の手がそのまま映ります。

## 対策の一覧

おすすめの順に並べています。1 は機材が要らないので、まず試してください。

### 1. 設定だけで済ませる（機材なし）

- **キャリブレーションは最後の 1 秒を平均する**（Phase 7 で追加。設定は不要）。カウントダウンの最後の 1 秒の間に一度でも手が見えていれば成功します。手の細かい震えも均されます。
- **自動モードを頭の傾きで判定する**。顎当てに顎を乗せると頭が左に傾くので、手を使わずに判定できます。
  ```json
  "auto": { "useLeftHand": false, "useHeadTilt": true }
  ```
  一度キャリブレーションをすると、構えたときの頭の傾き（`auto.headUp`）が記録されます。左手と頭の傾きの両方を使う設定（`useLeftHand: true, useHeadTilt: true`）にすると、左手を見失っている間は頭の傾きだけで判定します。
- **窓を手に追従させない**。既定どおり HMD 基準（`"anchor": { "type": "hmd" }`）にします。手に追従させる場合は `"onLost": "hold"`（既定）にすると、見失っても最後の場所に残ります。
- **部屋の環境**。Quest のハンドトラッキングはヘッドセットのカメラで手を見ています。部屋を明るくする、窓を背にしない（逆光を避ける）、手の背景をシンプルにすると外れにくくなります。

### 2. 楽器にトラッカーを付ける

楽器に SteamVR のトラッカーを付けると、手のトラッキングに関係なく「楽器を構えたか」が分かります。本アプリの機能（自動モード）に対しては、これが一番確実です。

- **付ける場所**: 楽器の重さのバランスと音を変えにくい場所にします。表板・駒・スクロールは避けて、顎当ての下や下側の側板（エンドピン側）など、本体の下の方にします。ニスを傷めないように、柔らかいマウントやストラップを使ってください。トラッカーは数十 g あるので、付けた状態で弾きやすいかを先に確かめてください。
- **設定**: 自動モードの判定をそのトラッカーで行います（シリアル番号の調べ方は下）。
  ```json
  "auto": { "useLeftHand": true, "deviceSerial": "LHR-XXXXXXXX" }
  ```
  キャリブレーションをすると、構えたときのトラッカーの位置が `auto.leftHandPosition` に記録されます（窓の位置は今までどおり両手の位置から決めます）。
- **窓を楽器に追従させる（任意）**: 頭を動かしても窓を楽器に合わせたままにしたいときは、窓をトラッカー基準にして、キャリブレーションします。キャリブレーションした瞬間の「トラッカーから見た窓の位置」が記録され、その後は楽器と一緒に動きます。
  ```json
  { "id": "fingerboard", "anchor": { "type": "device", "serial": "LHR-XXXXXXXX" }, ... }
  ```

### 3. 手首にトラッカーを付ける

左手首（手の甲側）か前腕にトラッカーを付け、左手の代わりに使います。

- **設定**: 自動モードとキャリブレーションの「左手」が、そのトラッカーになります。
  ```json
  "tracking": { "leftHandSerial": "LHR-XXXXXXXX" }
  ```
  シリアル番号を指定すると、トラッカーが見つからなくても手には戻りません（手首と手では位置がずれるため）。見つからないときは視界に `NO LEFT TRACKER` と出ます。
- **キャリブレーション**: 手首の位置が窓の左端になります。指先側が窓からはみ出すときは、`calibration.padMeters` を増やすか、キャリブレーション後に `widthMeters` を少し広げてください。
- 右手（弓）のトラッキングが外れる場合は、同じように `tracking.rightHandSerial` を使えます。
- 楽器のトラッカー（2）と両方付けた場合、自動モードは `auto.deviceSerial` を優先します。

### 4. VRChat のアバターの手について

アバターの手の動きは、VRChat がコントローラー（VD のハンドトラッキングでは VD がエミュレートするコントローラー）の姿勢から決めます。本アプリの設定やトラッカーでは変わりません。試せることを挙げますが、**どれも動作は未確認**です。

- **Quest のコントローラーを左前腕に固定する**: コントローラーはハンドトラッキングより外れにくいので、アバターの左手は安定します。ただしアバターの指は動かなくなります。また、片手だけコントローラーにしたときの Quest と VD の切り替えの動作は、実機で確かめる必要があります。
- **VD のハンドトラッキングの設定を見直す**: スムージングなどの設定で、外れたときの手の飛び方が変わる場合があります。

## トラッカーを Quest と一緒に使うには

Quest の位置（Quest のトラッキング）と、SteamVR トラッカーの位置（ベースステーション）は、そのままでは座標がずれています。

- **ベースステーションを使うトラッカー**（VIVE Tracker 3.0、Tundra Tracker など）: ベースステーションと、座標を合わせるツール（OpenVR Space Calibrator など）が必要です。
- **ベースステーションが要らないトラッカー**（VIVE Ultimate Tracker など）: 自分で位置を求めます。Quest と VD で使うときの手順や座標合わせは、製品の情報を確認してください。

座標がずれていると、窓や判定の位置もずれます。キャリブレーションは、座標合わせをした後に行ってください。

## シリアル番号の調べ方

`ViolinPassthrough.exe --console` で起動すると、接続中のデバイスが出ます（ログファイル `%APPDATA%\ViolinPassthrough\logs\` にも出ます）。

```
Tracked devices: #0 HMD "...", #1 Controller "...", #2 Controller "...", #3 GenericTracker "LHR-XXXXXXXX"
```

`GenericTracker` の後の文字列がシリアル番号です。設定したシリアル番号のデバイスが見つからないときは、ログに接続中のシリアル番号の一覧が出ます。
